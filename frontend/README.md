# Voces Palestinas por la Justicia Frontend

Aplicación Next.js para la plataforma Voces Palestinas por la Justicia.

## Tecnologías

- Next.js (App Router)
- React
- Tailwind CSS
- Axios
- SWR

## Instalación

```bash
npm install
cp .env.local.example .env.local
# Editar variable NEXT_PUBLIC_API_URL
npm run dev
